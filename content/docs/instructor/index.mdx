| 시간 | 내용 | 방식 |

| 3–13분 | 바이브 코딩 → 에이전틱 엔지니어링, 인스턴트 소프트웨어, **왜 Claude Code인가** | 강의 |

| 18–23분 | Claude Code 설치·로그인·화면 둘러보기 | 따라하기 |

| 33–35분 | 정리, 과제 안내 | 강의 |

- 실습 자료: `session1-practice.zip` → `산단_공유폴더_정리전` (40개). 팀 이름은 산학협력단 공개 업무 안내 기준, 내용은 모두 가상
- 첫 주 핵심 메시지 — 왜 Claude Code인가: ① 채팅·기획 문서·코드를 한 대화에서 오간다 ② 문서와 코드 모두 최상위 성능 (SWE-bench Verified 독립 측정 1위, 단 근소한 차이임을 솔직히) ③ 업무 파일을 직접 다룬다. 비교 표는 "다른 도구가 나쁘다"가 아니라 "용도가 다르다"로 전달
- 수업 직전 Arena(구 LMArena, arena.ai) 순위를 한 번 열어 최신 상황을 확인 (순위는 자주 바뀜)
- 시연 포인트 ① `다운로드 (3).pdf`를 이름이 아니라 내용으로 연구지원팀 공고라고 판단하는 장면 ② 계획에서 중복(`집행내역_과제03 (1)`, `IMG_5012 복사본`)과 뉴스레터 '최종' 3개를 스스로 짚는 장면
- 빠른 수강생은 선택 실습(진짜 최종 뉴스레터, 공모 마감 일정표, RISE 사진 날짜별)로 흡수
- 실제 업무 파일(개인정보·연구비 내역)은 실습에 쓰지 않도록 처음부터 강조. 반드시 가상 데이터로
- 권한 요청 창이 뜨면 "무엇을 하려는지 읽고 누르기"를 습관화
- 예상 질문 — "챗GPT랑 뭐가 다르냐": 답을 주는 것과 일을 끝내는 것의 차이. 시뮬레이터로 보여 주기
- 예상 질문 — "학교 문서가 밖으로 나가는 것 아니냐": 6회차 보안 파트에서 자세히. 여기서는 "대화 내용은 AI 모델로 전송된다"는 사실을 솔직하게
