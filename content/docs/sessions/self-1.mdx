<DeepDive title="Claude Code 데스크톱 앱 화면, 하나씩 짚어 보기">

| 위치 | 이름 | 하는 일 |
| --- | --- | --- |
| 상단 | **Code** 탭 | Claude Code 작업 공간. 웹 채팅(Chat)과 구분됩니다 |
| 위쪽 | **폴더 선택** | 이번 대화에서 AI가 다룰 폴더. 이 폴더 밖은 건드리지 않습니다 |
| 아래 | **입력창** | 지시를 쓰는 곳. 파일을 끌어다 놓거나 `@파일명`으로 가리킬 수 있습니다 |
| 입력창 옆 | **모드 메뉴** | 플랜 모드(계획만) 등 작업 방식을 고릅니다 |
| 대화 중 | **권한 요청** | 파일 수정·명령 실행 전에 허락을 구하는 창 |
| 왼쪽 | **대화 목록** | 이전 작업을 다시 열어 이어서 할 수 있습니다 |

**대화 하나 = 작업 하나**로 생각하면 편합니다. 주제가 바뀌면 새 대화를 열거나 `/clear`로 비우세요. 대화가 길어질수록 AI가 앞부분을 덜 정확하게 기억합니다.

</DeepDive>

<DeepDive title="챗봇과 에이전트, 한 번 더">

이 차이 때문에 사람의 역할도 바뀝니다. 손으로 하던 일이 줄고, **무엇을 시킬지 정하고 결과를 확인하는 일**이 늘어납니다. 행정 업무에서 기안하고 결재하던 능력이 그대로 쓰입니다.

</DeepDive>

## 2일차 지시를 바꾸면 결과가 바뀐다

오늘은 **같은 일을 두 가지 방식으로** 시켜 보고 결과를 비교합니다. 프롬프트를 잘 쓰는 감각은 이렇게 직접 비교해 볼 때 가장 빨리 늡니다.

<DeepDive title="좋은 지시의 네 가지 조건">

1. **대상이 분명하다** — "파일들"이 아니라 "이 폴더의 PDF", "@연구윤리교육_이수현황.xlsx"
2. **결과 모양이 있다** — "표로", "파일로 저장", "5줄로"
3. **하지 말 것이 있다** — "지우지 마", "원본은 그대로", "아직 실행하지 마"
4. **확인 기준이 있다** — "개수가 맞는지 확인해줘", "찾지 못하면 '확인 필요'로"

2회차에서는 이것을 **목적·입력·출력·조건·검증** 5요소로 정리합니다. 오늘은 네 가지만 기억하세요.

</DeepDive>

## 3일차 계획 보기와 되돌리기

<DeepDive title="플랜 모드, 언제 쓰고 언제 안 써도 되나">

| 이런 일이면 | 플랜 모드 | 이유 |
| --- | --- | --- |
| 파일 여러 개를 옮기거나 이름을 바꿈 | **켠다** | 되돌리기 번거롭고, 한 번에 많이 바뀜 |
| 처음 해 보는 작업, 방법을 모르겠음 | **켠다** | 계획을 보며 방법을 배울 수 있음 |
| 표 하나 보여 주기, 요약하기 | 안 켜도 됨 | 아무 파일도 바뀌지 않음 |
| 오탈자 하나 고치기 | 안 켜도 됨 | 한 문장으로 설명되는 작은 일 |

플랜 모드를 켜지 않고 문장에 **"아직 실행하지 말고 계획만 보여줘"**라고 써도 비슷한 효과가 납니다.

</DeepDive>

<DeepDive title="되돌리는 방법 세 가지">

| 방법 | 언제 | 어떻게 |
| --- | --- | --- |
| <Kbd keys="esc" /> | AI가 작업하는 도중 멈추고 싶을 때 | 한 번 누르면 멈춥니다. 대화는 남습니다 |
| <Kbd keys="esc" /> 두 번 또는 `/rewind` | 방금 한 작업을 통째로 되돌릴 때 | 되돌아갈 시점을 고르면 파일까지 그때로 돌아갑니다 |
| 말로 요청 | 어떤 부분만 되돌릴 때 | "방금 옮긴 사진만 원래 자리로 돌려줘" |

3회차에서 배우는 **Git**은 여기에 더해, 며칠 전 상태로도 돌아갈 수 있는 세이브 포인트입니다.

</DeepDive>

## 4일차 문서도 맡겨 보기

Claude Code는 코드만 쓰는 도구가 아닙니다. 공유폴더의 자료를 읽고 **안내문, 보고서, 일정표 같은 문서**도 파일로 써 줍니다. 오늘은 기획·문서 쪽 능력을 써 봅니다.
