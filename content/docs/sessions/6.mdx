## 개념

### 만드는 AI와 일하는 AI

| 구분 | ChatGPT Codex 앱 | OpenAI API |
| --- | --- | --- |
| 역할 | 내가 말하면 프로그램을 만들어 줌 | 내가 만든 프로그램 안에서 매번 일함 |
| 쓰는 사람 | 나 (개발할 때) | 앱을 쓰는 동료 모두 |
| 비용 | ChatGPT 요금제 | 사용한 만큼 별도 과금 (<Term id="token">토큰</Term> 단위) |
| 예시 | "업무 요청 보드 앱을 만들어줘" | 앱 안의 [자동 분류·요약] 버튼 |

지능형 기능의 세 가지 기본형만 기억하면 대부분의 업무 아이디어가 나옵니다.

| 기본형 | 하는 일 | 일반 기업 예시 |
| --- | --- | --- |
| **요약** | 긴 글을 짧게 | 공문·회의록·보고서를 5줄로 |
| **추출** | 글에서 정해진 항목을 뽑아 표의 칸으로 | 요청문 → 요청 부서·희망일·긴급도 |
| **분류** | 정해진 범주로 나누고 다음 행동 제안 | 요청 → IT/총무/구매/재무 + 담당자 후보 |

### API 키와 비용 감각

- **키 발급:** [OpenAI API 플랫폼](https://platform.openai.com/)에서 프로젝트를 만들고 API 키를 발급합니다. 결제 방식·사용 한도 화면은 바뀔 수 있으므로 [공식 결제 문서](https://platform.openai.com/docs/guides/production-best-practices/managing-billing-limits)를 확인하세요.
- 키는 5회차와 같은 원칙: `.env.local`과 Vercel 환경변수에만, 그리고 **서버 쪽 코드에서만** 호출합니다. 브라우저 코드에 넣으면 누구나 내 키로 과금시킬 수 있습니다.
- 요금은 읽은 양(입력)과 쓴 양(출력)의 토큰 수로 계산합니다.

### 어떤 모델을 쓸까

모델 이름·가격·지원 기능은 자주 바뀝니다. 특정 이름을 외우지 말고 [OpenAI 모델 문서](https://platform.openai.com/docs/models)와 [API 요금표](https://openai.com/api/pricing/)에서 현재 모델을 확인합니다. 먼저 비용이 낮은 모델로 가상 데이터 정확도를 측정하고, 기준을 못 넘을 때 상위 모델을 비교합니다.

## 보안·거버넌스: 회사에서 쓸 때의 7원칙

<Sim name="injection" />

1. **데이터 등급을 먼저 나눈다.** 공개 가능 / 내부용 / 개인정보·민감정보. 마지막 등급은 회사 지침과 보안 담당 부서 협의 없이 AI에 넣지 않는다.
2. **계정과 API 데이터 정책을 확인한다.** 회사 도입 전 [OpenAI 엔터프라이즈 개인정보 안내](https://openai.com/enterprise-privacy/)와 현재 계약 조건을 확인한다.
3. **키는 비밀번호다.** 코드·채팅·메신저에 남기지 않고, 노출되면 즉시 재발급한다.
4. **사용 한도를 걸어 둔다.** Console 월 한도, Vercel·Supabase 요금 알림.
5. **AI 결과는 초안이다.** 금액·날짜·수신자처럼 틀리면 안 되는 값은 사람이 확인하고 저장·발송한다.
6. **외부 문서 속 지시문을 조심한다.** 공고문·메일·웹페이지에 숨긴 문장으로 AI를 조종하는 공격(<Term id="prompt-injection">프롬프트 인젝션</Term>)이 있다.
7. **만든 사람이 떠나도 남는가를 묻는다.** 동료가 매일 쓰는 도구가 되면 기획서·AGENTS.md·GitHub 저장소를 팀 계정으로 옮기고, 필요하면 IT팀에 이관한다.
