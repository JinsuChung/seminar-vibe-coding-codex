## 개념

### 데이터베이스 = 문단속하는 공유 엑셀

| 엑셀 | 데이터베이스 |
| --- | --- |
| 시트 | <Term id="table">테이블</Term> (예: `requests`, `event_signups`) |
| 열 제목 | <Term id="column">컬럼</Term> (사업명, 마감일, 담당자) |
| 한 줄 | <Term id="row">행</Term> (업무 요청 1건) |
| 파일을 메일로 돌리기 | 웹앱이 한곳에서 읽고 씀 |
| 누구나 아무 칸이나 수정 | **누가 무엇을 보고 쓸지 규칙으로 제한** |

<Analogy title="왜 엑셀 공유로는 안 될까">
  공유 엑셀은 누가 언제 무엇을 지웠는지 알기 어렵고, 동시에 고치면 충돌하고, 특정 사람에게만 일부 행을 보여 주기 어렵습니다. 데이터베이스는 이 세 가지를 규칙으로 해결합니다.
</Analogy>

### Supabase와 Neon — 무엇을 고를까

| 항목 | Supabase | Neon |
| --- | --- | --- |
| 정체 | DB + 로그인 + 파일 저장 + 관리 화면 묶음 | DB(PostgreSQL)에 집중 |
| 무료 한도 | <Fact k="supabase.free" /> | <Fact k="neon.free" /> |
| 유료 시작 | <Fact k="supabase.pro" /> | 사용량 기반, 월 최소금액 없음 |
| 비개발자에게 | 표 편집 화면이 엑셀처럼 쉬움, 로그인 기능 내장 | Vercel 대시보드에서 바로 연결 가능 |
| 이 과정의 선택 | **기본 실습** | 대안 소개 |

### 테이블 설계 연습: 엑셀을 테이블로

업무 요청 목록 엑셀이 있다고 생각해 봅시다. 열마다 **어떤 종류의 값**인지 정하는 것이 테이블 설계입니다.

| 엑셀 열 | 컬럼 이름 | 값의 종류 | 왜 |
| --- | --- | --- | --- |
| (자동 번호) | `id` | 숫자, 자동 | 행마다 고유한 번호 |
| 요청 제목 | `title` | 글자, 필수 | |
| 요청 부서 | `department` | 글자, 필수 | |
| 희망 완료일 | `due_date` | 날짜, 필수 | 날짜로 저장해야 D-day 계산·정렬이 됨 |
| 담당자 | `owner` | 글자 | |
| 상태 | `status` | 글자, 필수 | 접수·진행·완료로 제한 |
| 등록 시각 | `created_at` | 시각, 자동 | 언제 등록됐는지 |

설계 초안은 Codex가 만들 수 있지만, **표를 읽고 이상한 점을 물어보는 것**은 사람의 일입니다.

### 보안 3원칙 — 바이브 코딩 사고의 대부분이 여기서 난다

1. **키는 환경변수에.** DB 접속 키를 코드에 직접 적지 않습니다. 내 PC는 `.env.local`, 배포본은 Vercel 환경변수 메뉴에. `.env.local`이 `.gitignore`에 있는지 확인합니다.
2. **두 개의 키를 구분.** 화면에 노출돼도 되는 <Term id="anon-key">공개 키</Term>와, 모든 권한을 가진 <Term id="service-key">비밀 키</Term>. 비밀 키는 절대 브라우저 쪽 코드에 넣지 않습니다.
3. **<Term id="rls">RLS</Term>(행 수준 보안)를 켠다.** 예: "로그인한 직원은 읽기, 요청자는 자기 요청만 수정, 담당자는 상태 변경".

## 시연

강사가 Supabase 화면(프로젝트 생성 → SQL Editor → Table Editor → API 키 위치)을 한 번 따라가 보여 줍니다. Supabase 화면은 영문이므로 버튼 이름을 함께 짚습니다.

| 화면 | 위치 | 하는 일 |
| --- | --- | --- |
| **New project** | 대시보드 첫 화면 | 프로젝트 이름, DB 비밀번호, 리전 선택 |
| **SQL Editor** | 왼쪽 메뉴 | 검토한 SQL을 붙여 넣고 **Run** |
| **Table Editor** | 왼쪽 메뉴 | 엑셀처럼 데이터를 보고 고침 |
| **Project Settings → API** | 왼쪽 아래 톱니바퀴 | Project URL과 공개 키(anon/publishable) 복사 |
