## 1주차 하나만 고른다

<DeepDive title="좋은 첫 도구의 조건">

| 조건 | 왜 |
| --- | --- |
| **매주 또는 매달 반복**되는 일 | 만든 보람이 계속 돌아옴 |
| **30분 이상** 걸리는 일 | 줄어든 시간이 눈에 보임 |
| **입력과 결과가 분명**한 일 | 검증 기준을 쓰기 쉬움 |
| **개인정보가 없거나 가릴 수 있는** 일 | 바로 시작할 수 있음 |
| **나 또는 우리 팀만** 쓰는 일 | 로그인·운영 부담이 없음 |

처음부터 웹앱·데이터베이스·AI를 다 넣지 마세요. **2회차 수준(내 PC 도구)으로 시작해 필요할 때만 키우는 것**이 성공 확률이 가장 높습니다. 무엇을 만들지 모르겠다면 [업무 예시 30](/examples)에서 내 업무와 가장 가까운 것을 고르세요.

</DeepDive>

## 4주차 계속 쓸지 정하기

<DeepDive title="운영 판단표 (6회차 복습)">

| --- | --- | --- |
| 나 혼자 또는 소수만 쓰나? | 내 PC·Hobby 배포 | 사용자 관리·로그인 필요 |
| 개인정보가 없나? | 그대로 사용 | 개인정보 처리 절차·보안 심사 |
| 멈춰도 업무가 돌아가나? | 그대로 사용 | 장애 대응·유료 요금제 |
| 돈이 오가거나 외부에 공개되나? | 아니오면 그대로 | 상업용 요금제·회사 승인 |
