## ChatGPT Codex 앱

설치 경로, 지원 운영체제, 이용 가능한 요금제와 모델 이름은 바뀔 수 있습니다. 수업 직전 [OpenAI Codex 공식 문서](https://developers.openai.com/codex/)와 [OpenAI 요금 안내](https://openai.com/chatgpt/pricing/)를 확인하세요.

### 방법 1. 데스크톱 앱 (권장)

터미널을 쓰지 않아도 되어 비개발자에게 가장 편합니다.

<Steps>
<FdStep>
[ChatGPT 다운로드 페이지](https://openai.com/chatgpt/download/)에서 운영체제에 맞는 앱을 내려받아 설치합니다.
</FdStep>
<FdStep>
앱을 열고 ChatGPT 계정으로 로그인합니다. 비밀번호와 인증은 본인이 직접 입력합니다.
</FdStep>
<FdStep>
Codex 작업 화면을 열고 작업할 폴더(예: 압축을 푼 실습 폴더)를 선택합니다. 화면 이름은 버전에 따라 다를 수 있습니다.
</FdStep>
<FdStep>
입력창에 `이 폴더에 어떤 파일이 있는지 알려줘`라고 써 보세요. 답이 오면 설치 완료입니다.
</FdStep>
</Steps>

### 터미널 방식이 필요한 경우

이 과정은 데스크톱 앱을 기준으로 합니다. CLI가 필요한 환경이라면 명령을 오래된 교안에서 복사하지 말고 [OpenAI Codex 공식 문서](https://developers.openai.com/codex/)의 현재 설치 명령과 로그인 방식을 확인하세요.
