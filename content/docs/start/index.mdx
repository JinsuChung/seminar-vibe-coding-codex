6회차를 마치면 **자기 업무에 필요한 작은 소프트웨어를 직접 기획하고, Claude Code로 만들고, 필요하면 인터넷에 배포**할 수 있습니다.

<Callout title="핵심 메시지">
  기획하는 사람이 곧 만드는 사람이 된다. AI는 만들고, 사람은 정의하고 승인하고 검증한다.
</Callout>

## 누구를 위한 과정인가요

| 항목 | 내용 |
| --- | --- |
| 대상 | 삼육대학교 산학협력단 직원 (코딩 경험 없음 가정) |
| 강의 | 삼육대학교 기획처 정진수 과장 |
| 방식 | 회차마다 개념 10분 + 시연 10분 + 실습 15–20분 |
| 결과물 | 매 회차 "내 컴퓨터에 남는 것" 하나 |

## 6회차 로드맵

| 회차 | 주제 | 실습 결과물 | 주요 도구 |
| --- | --- | --- | --- |
| [1](/sessions/1) | 바이브 코딩에서 에이전틱 엔지니어링으로 | Claude Code 설치, 산단 공유폴더 팀별 정리와 현황 보고서 | Claude Code 데스크톱 앱 |
| [2](/sessions/2) | 인스턴트 소프트웨어: 쓰고 지우는 내 업무 도구 | 엑셀 취합기, 파일 일괄 정리, HTML 계산기 | 플랜 모드, CLAUDE.md |
| [3](/sessions/3) | Git과 GitHub: AI와 일할 때의 안전망 | 커밋 이력이 있는 프로젝트, GitHub 저장소 | Git, GitHub |
| [4](/sessions/4) | 웹앱으로 키우고 Vercel로 배포하기 | 링크로 공유하는 공모 D-day 보드 | Next.js, Vercel |
| [5](/sessions/5) | 데이터베이스 붙이기: 접수·신청형 업무 앱 | 화면에서 추가·수정되는 공모 보드 | Supabase |
| [6](/sessions/6) | AI API로 지능형 업무 도구 만들기 + 안전하게 쓰기 | 공고문 자동 추출·등록 기능 | Claude API |

1–2회차는 **로컬(내 PC)**, 3회차는 **안전망**, 4–6회차는 **서버와 클라우드**로 단계가 올라갑니다. 4–6회차는 공모 보드 하나를 계속 키워 가는 이어지는 실습입니다.

### 회차 사이: 혼자 해 보기 (1.5 ~ 6.5)

수업이 일주일에 한 번이라 감각을 잃지 않도록, 회차 사이마다 **혼자 해 보기** 페이지가 있습니다. 하루 15~25분씩 4~5일, 주당 약 90분입니다. 지난 회차 복습 → 수업에서 못 다룬 상세 설명 → 실습 미션 → 내 업무 적용 → 다음 회차 준비 순서로 되어 있고, 궁금한 점은 적어 두었다가 다음 수업 시작 때 함께 풉니다.

| 과정 | 이번 주에 할 일 |
| --- | --- |
| [1.5](/sessions/self-1) | Claude Code와 친해지기: 지시하는 법, 계획 보기, 되돌리기, 문서 작성 |
| [2.5](/sessions/self-2) | 엑셀·파일 도구 더 만들기: 검증 기준 쓰기, 내 업무 도구 첫 버전 |
| [3.5](/sessions/self-3) | 커밋하는 습관 들이기: 되돌리는 세 가지 방법, GitHub 화면 |
| [4.5](/sessions/self-4) | 공모 보드 키우기: 혼자 배포, 1회차 데이터로 채우기, 기능 추가 |
| [5.5](/sessions/self-5) | 데이터와 보안: SQL·RLS 읽기, 두 계정 권한 시험, 항목 추가 |
| [6.5](/sessions/self-6) | 과정 이후 4주 로드맵: 내 업무 도구 하나를 끝까지 |
